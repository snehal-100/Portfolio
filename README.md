## 🎨 Interactive Portfolio Highlights

The portfolio is designed with a futuristic **Cyberpunk / Systems Telemetry** aesthetic and features zero third-party UI framework dependencies:

- **Web Audio Synthesizer Engine:** Native Web Audio API audio subsystem synthesizing keypress blips, click hums, and UI glitch sound effects directly in the browser with mute/sound controls.
- **Dual HTML5 Canvas Visual FX:** High-performance background constellation mesh with mouse repulsion physics and a secondary canvas particle engine for visual bursts.
- **Interactive Architecture Schematics:** Live SVG wiring diagrams with animated packet pulses demonstrating data flow between client, server, cache, and database tiers.
- **Interactive Project Consoles:** Hovering over project dossiers triggers dynamic typewriter-style server telemetry and terminal logs.
- **Educational Transit Map:** Metro station transit visualization mapping academic milestones from high school through engineering graduation.
- **Honeycomb Skills & Telemetry HUD:** Interactive hexagonal skill matrix linked with a live technical proficiency inspector.
- **Interests & Mini-Lab Nexus:** 
  - *Reflex Decryptor:* 3x3 node decryption mini-game.
  - *Audio Synthesizer:* Musical frequency pads (C4–G4) with real-time waveform visualization.
  - *Anime Quote Generator & Lore Dossier:* Interactive terminal reader.
- **Theme Engine:** Fully integrated dark and light themes with smooth CSS variable transitions and `localStorage` persistence.

## 💻 Local Development

Run the portfolio locally with any local web server:

```bash
# 1. Clone the repository
git clone https://github.com/snehal-100/Portfolio.git

# 2. Navigate to project root
cd Portfolio

# 3. Launch with Python built-in server (or VS Code Live Server)
python -m http.server 8000
```

Open `http://localhost:8000` in any modern web browser.
